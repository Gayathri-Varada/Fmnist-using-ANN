## Project Overview
This project focuses on building an Artificial Neural Network (ANN) using PyTorch to classify handwritten digits from the MNIST dataset. The model was trained and evaluated to recognize digits from 0 to 9, achieving approximately 90% accuracy.

## Technologies Used
- Python
- PyTorch
- NumPy
## Key Concepts
- MNIST dataset loading and preprocessing
- Building an Artificial Neural Network using PyTorch
- Forward propagation and backpropagation
- Automatic differentiation using Autograd
- Loss function and optimizer selection
- Model training and validation
- Hyperparameter tuning using Optuna
- Model evaluation using accuracy
  
## Results
Achieved approximately **90% classification accuracy** on the MNIST dataset.

## Key Learnings
- Understanding the fundamentals of neural networks
- Implementing neural network training using PyTorch
- Understanding gradient computation and weight updates
- Optimizing model hyperparameters using Optuna
- Evaluating model performance on image classification tasks
